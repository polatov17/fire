# fire

A clean, responsive portfolio website showcasing my projects, skills, and contact information.

## Sections

- **Home**: introduction and call to action
- **About**: who I am and what I do
- **Projects**: selected work with links
- **Skills**: tools and technologies
- **Contact**: email and social links

## Getting Started

    git clone https://github.com/YOUR-USERNAME/firebluary.git
    cd firebluary

Open `index.html` in your browser, or run a local server:

    npx serve .

## Deployment

Hosted for free with GitHub Pages:
Settings → Pages → Branch: main → Save.
