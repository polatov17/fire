# 🔥 Fire Portfolio

A modern, fast and responsive personal portfolio website to showcase my projects, skills and contact details.

## ✨ Features

- 📱 Fully responsive (mobile, tablet, desktop)
- ⚡ Lightweight and fast, no heavy frameworks
- 🎨 Clean and minimal design
- 🔗 Easy-to-edit project and social links

## 📂 Sections

| Section  | Description                      |
| -------- | -------------------------------- |
| Home     | Introduction and call to action  |
| About    | Who I am and what I do           |
| Projects | Selected work with links         |
| Skills   | Tools and technologies           |
| Contact  | Email and social links           |

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/fire.git
cd fire
```

Open `index.html` in your browser, or run a local server:

```bash
npx serve .
```

## 🌐 Deployment

This site is hosted for free with GitHub Pages:

1. Go to **Settings**
2. Open **Pages**
3. Choose **Branch: main**
4. Click **Save**

Your site will be live at `https://YOUR-USERNAME.github.io/fire/`.
